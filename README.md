# 基于BIM标准的参数补全验证工具

医疗工艺研究中心 · 庄泽锋

本项目将BIM交付标准转为可执行的专业规则，通过DeepSeek审查与修改智能体、逐轮复检和可视化反馈，帮助工程师整理已有IFC的名称、分类与属性。

本仓库用于发布安装包和使用说明。最新版本为 **v0.8.1**，包含 **Revit 2019插件版** 和 **独立WPF桌面版** 两个完整安装包。

请前往 [Releases](https://github.com/hszzhua2/bim-standard-fill/releases/latest) 下载。选择适用的 `.exe` 后安装，无需先安装旧版。

## 业务流程

选择IFC与专业 → 配置标准和模型 → 规则定位 → 智能体提出修改 → 独立审查 → 写入副本 → 完整复检 → 工程复核 → 集中导出。

支持 `deepseek-flash` / `deepseek-v4-pro` 模型切换、网络重试与检查点续跑。前后图表展示检查比例、构件分类、修改明细和剩余待办。

## 使用条件

- Windows 10/11 x64，.NET Framework 4.7.2+，内嵌图表需WebView2 Runtime。
- 插件版使用Revit 2019；独立桌面版无需Revit。
- 在线补全使用自己的官方DeepSeek密钥，并按批允许发送必要构件摘要。
- 原始模型保留，修改生成副本；估算和分类推断进入工程复核。

本地规则折算达到95分并满足交付检查及完整结构校验后列入成品待工程复核。正式交付按项目检查和专业签认程序执行。
